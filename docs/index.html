Contra ZAP — API

Duas rotas HTTP e 42 eventos socket.io. As rotas estão no Swagger abaixo; os eventos, que são o jogo inteiro, têm um playground que conecta de verdade no servidor.

Postman collection Postman environment OpenAPI 3.1 openapi.yaml AsyncAPI 3.1 asyncapi.yaml

Por que o Swagger é tão curto. O projeto tem exatamente duas rotas HTTP: /health e /. Não é documentação faltando — o front React não faz uma única chamada HTTP. Login, salas, apostas, cartas e chat trafegam por socket.io.

Por isso existem duas specs. openapi.yaml cobre o HTTP; asyncapi.yaml cobre o protocolo de eventos (AsyncAPI é o padrão para APIs orientadas a evento — OpenAPI não descreve request/response por ack).

O Swagger UI não carregou. Ele vem de CDN e precisa de internet. O playground abaixo e os downloads acima continuam funcionando normalmente — e o openapi.yaml pode ser aberto em qualquer editor de OpenAPI.
